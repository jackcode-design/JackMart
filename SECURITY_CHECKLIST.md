# Weeks 7–8 Setup

These files extend the existing JackMart Weeks 1–6 implementation.

## 1. Copy
Keep the existing `JackMart` project and copy these Week 7–8 files into the same paths.

## 2. Build
Use JDK 17 and Maven:

```bash
mvn clean test
mvn clean package
```

The expected WAR is:

```text
target/jackmart.war
```

## 3. Security checks
Before deployment verify:
- every SQL statement uses `PreparedStatement`;
- passwords are BCrypt hashes;
- protected routes reject unauthenticated sessions;
- seller/admin routes enforce their roles;
- JSP user values are rendered with JSTL escaping;
- error pages do not expose stack traces;
- database credentials are not committed.

## 4. Local Tomcat
Copy `target/jackmart.war` to Tomcat 9 `webapps/`, start Tomcat, then open:

```text
http://localhost:8080/jackmart/
```

Health endpoint:

```text
http://localhost:8080/jackmart/api/v1/health
```

## 5. Live deployment
Use `deploy/scripts/deploy.sh` on the Linux/Tomcat server after setting the required environment variables. Then run:

```bash
deploy/scripts/smoke-test.sh https://YOUR-DOMAIN/jackmart/api/v1/health
```

Replace `YOUR-DOMAIN` with the actual deployed hostname.

## Important
The deployment URL is environment-specific and is not generated by this package. Record the real URL in `README.md` after deployment.
