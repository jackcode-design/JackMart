# JackMart — Weeks 3–6 Acceptance Checklist

| Week | Feature | Acceptance test |
|---|---|---|
| 3 | Seller create | SELLER creates valid listing |
| 3 | Seller edit | Seller edits own listing |
| 3 | Ownership | Seller cannot edit/delete another seller's listing |
| 3 | Seller orders | Seller sees orders containing their products |
| 4 | Admin users | ADMIN can list users |
| 4 | Admin orders | ADMIN can list orders |
| 4 | Moderation | ADMIN can remove a product |
| 4 | Role security | BUYER/SELLER receive 403 on admin routes |
| 5 | Search | Keyword and category filters work together |
| 5 | Status | Pending → Confirmed → Shipped → Delivered |
| 5 | Transition guard | Invalid backward/skip transition rejected |
| 6 | Review | Delivered-order buyer can submit 1–5 rating |
| 6 | Review guard | Non-buyer cannot review product |
| 6 | Duplicate guard | Same buyer/product cannot be reviewed twice |
| 6 | Checkout | Empty cart is rejected |
| 6 | Stock | Quantity above stock is rejected |
