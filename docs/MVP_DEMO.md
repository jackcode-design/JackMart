# MVP Demo Script

1. Open JackMart.
2. Register a new Buyer.
3. Log in.
4. Browse the seeded products.
5. Search for a product or filter by category.
6. Add a product to the cart.
7. Change quantity and verify the total.
8. Remove/re-add an item if needed.
9. Proceed to checkout.
10. Confirm the mock payment.
11. Open order history.
12. Show the new order and total.

Expected result: one complete end-to-end journey from registration/login through browse, cart and order placement.
