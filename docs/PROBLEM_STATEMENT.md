# Problem Statement

Small sellers and buyers need a simple marketplace where sellers can list products and buyers can browse products, manage a cart and place orders. JackMart provides a Java Servlet/JDBC based multi-seller marketplace foundation with role-aware authentication, product browsing, cart handling and a mock checkout flow.

## 2-week MVP
The first two weeks focus on authentication and the core buyer purchase journey so that the project can demonstrate one complete end-to-end transaction.
